# AI Tool Usage

ETHGlobal requires disclosure of AI assistance, including which tools were used,
what they were used for, and any spec or prompt artifacts that drove generation.
This file is that disclosure and is updated as the project develops.

## Tools

| Tool | Used for |
| --- | --- |
| Cursor (agent mode) | Scaffolding, implementation of the gateway modules, the Solidity contract, the demo page, and documentation drafts. |

## What AI was used for

- **Research.** Reading partner documentation and API references for The Graph, Hedera, the Blocky402 facilitator, and Bazantic. Every factual claim was verified against the source page.
- **Specification.** A written spec was drafted with AI assistance from a human-directed design, then revised by hand. It is kept outside this repository as working notes. The core design decision — splitting `verify` and `settle` so that refusals are free — was a human call made after reading the Blocky402 API reference.
- **Implementation.** Module scaffolding and first-draft implementations across `src/`, `contracts/`, `mcp/`, `client/`, `agent/`, and `public/`.
- **Tests.** The value-conservation and freshness property tests in `test/`.

## What was verified by hand, not taken on trust

- The Blocky402 facilitator API shape was checked against the live
  `GET https://api.testnet.blocky402.com/supported` response, not assumed from
  documentation or model memory.
- Every npm dependency version was confirmed to exist via `npm view` before use.
- The 402 response, the live fee-payer lookup, and the health endpoint were
  confirmed by running the service and inspecting real HTTP responses.
- No source deployment IDs were generated by a model. `registry/families.json`
  ships with explicit `<FILL: ...>` placeholders precisely so that no
  plausible-looking but fabricated identifier can enter the serving path, and
  `npm run registry:doctor` fails on them.

## Prompt and spec artifacts

- A master specification document, written first and implemented against. Kept as
  working notes outside this repository; available on request.
- `mcp/SKILL.md` — the agent-facing instruction file shipped with the MCP server.
